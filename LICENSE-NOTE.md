# Licensing and attribution

No license is included by default. Before selecting a software license, verify ownership and permission to redistribute team-authored notebooks, the presentation, and any third-party images.

The small example CSV is derived from the provided dataset. Confirm that the upstream Dryad dataset license permits redistribution and retain its required attribution. Reference source: https://doi.org/10.5061/dryad.2jm63xsrf

The presentation includes illustrative imagery and must not be treated as independently licensed for reuse without checking rights. If permissions are unclear, keep the deck out of a public GitHub repository.
